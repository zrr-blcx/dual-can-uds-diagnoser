# Security Policy

## Supported Versions

Security fixes are applied to the current `main` branch and the latest tagged
release when one exists.

## Reporting a Vulnerability

Do not open a public issue for a vulnerability or include secrets, device
serial numbers, private keys, or local machine details in a report.

Use GitHub private vulnerability reporting:

https://github.com/zrr-blcx/dual-can-uds-diagnoser/security/advisories/new

Include the affected component, reproduction steps, impact, and any suggested
fix. Reports are reviewed on a best-effort basis.

The Seed/Key implementation in the repository is a test/demo algorithm. It must
not be treated as production ECU security.
