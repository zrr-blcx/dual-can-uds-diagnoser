# CAN-UDS 双节点诊断项目

## 项目目标

在 STM32F407 与 STM32F103 两个真实 CAN 节点上验证：

- 500 kbps CAN 通信、错误状态和 Bus-Off 恢复；
- ISO 15765-2 多帧传输与流控；
- UDS 会话、DID 读写、安全访问和例行控制；
- Python 诊断仪的双节点调度、时序处理与故障分析；
- 参数持久化、启动自检和可复现的硬件验收流程。

## 系统组成

```text
PC diagnostic tool
  -> CANable / python-can
  -> CAN bus
  -> F407 ECU (0x7E0/0x7E8)
  -> F103 ECU (0x7E1/0x7E9)
```

固件采用 STM32CubeIDE + HAL，共享 CAN、ISO-TP、UDS、参数存储和看门狗模块。
PC 工具支持真实 CANable、MemoryBus 和 VirtualEcu。

## 已验证范围

- 双节点 CAN 基础通信、Bus-Off 恢复和看门狗；
- 双向 100/120 字节 ISO-TP 传输与四类超时；
- `0x10/0x22/0x27/0x2E/0x31/0x3E` 服务；
- F407/F103 参数掉电保持和 `0x78 -> 最终响应` 时序；
- 双节点 NRC 矩阵、Python 诊断仪和 udsoncan 互操作。
