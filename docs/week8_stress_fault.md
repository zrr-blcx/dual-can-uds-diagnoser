# 第 8 周：压力测试与故障注入

## 范围

本阶段验证双节点 CAN/UDS 系统在背景负载、请求频率提高和受控故障下的
可观测性。测试使用 F407/F103 的真实 CAN 总线、500 kbps 位率、现有
SN65HVD230 终接和故障继电器。

测试功能通过隔离构建开关启用：

- `-DbcBench`：发送 DBC 示例信号，用于第 7 周实机复验。
- `-BenchTest`：启用背景帧序号探针和 `0xF1A0` 硬件故障钩子。
- `-StressMaster`：由一侧 MCU 生成 90%+ 背景帧并直接向另一侧发 UDS。

正式固件不包含这些报文和测试钩子。

## 负载生成

单只 slcan CANable 同时生成高负载并接收多帧响应时会出现适配器侧丢帧，
因此 90% 测试改用板内测试员：

- 背景帧 ID 使用低优先级 `0x7F0`，避免抢占 `0x7E8/0x7E9`。
- 背景周期为 228 us，载荷前缀为 32 位连续序号，尾部使用 `55 55 55 55`。
- UDS 请求使用单帧 `22 F19A`，响应为 8 字节原始 CAN 单帧。
- 请求启动间隔为 20 ms，每方向 1000 次。
- 测试员使用 DWT 周期计数器调度；发送邮箱被占用或错过期限时跳过，不追赶突发。
- 被测节点用 `BackgroundProbe` 统计接收序号、缺口和乱序。

## 低负载基线

条件：10% 背景负载、100 ms 间隔、每节点 1000 次、`retries=0`。

| Node | Success | Timeout | Error | Physical gaps | Avg RTT | Max RTT |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| F407 | 1000/1000 | 0 | 0 | 0 / 45,036 | 64.37 ms | 91.08 ms |
| F103 | 1000/1000 | 0 | 0 | 0 / 45,036 | 66.67 ms | 86.59 ms |

基线物理丢帧率为 0，满足正常负载 `<0.1%` 门禁。

## 90%+ 压力结果

| DUT | Effective load | Success | Timeout | Physical gap loss | Avg RTT | Max RTT |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| F103 | 94.40% | 524/1000 | 476 | 3.476% | 1.969 ms | 2.713 ms |
| F407 | 94.41% | 517/1000 | 483 | 3.812% | 1.756 ms | 2.843 ms |

高负载成功率约 51%，说明当前固件在 90%+ 场景下会出现明显降级。该结果
作为第 8 周压力验收和后续优化输入，不等同于正常负载终测失败。

## 故障注入

| Scenario | F407 | F103 | Notes |
| --- | --- | --- | --- |
| DTC status | PASS | PASS | `0xF1A0` 注入后由 `0xF191` 读回 |
| NRC on service `0x22` | PASS | PASS | 返回 `7F 22 31` |
| Communication loss | PASS | PASS | 请求超时后自动恢复 |
| Relay Bus-Off | PASS | Shared bus | 复用第 2 周 CH2 物理 3/3 恢复结果 |
| Formal restore | PASS | PASS | 双节点各 20/20 读取 |

## 回归与恢复

- 完整 pytest：`125 passed`
- F407 正式构建：`text=34160, data=44, bss=9164`
- F103 正式构建：`text=32072, data=20, bss=9192`
- F407 Sector 11 测试前后 SHA-256：
  `F91D4632E085748F5BB1E38FFD8F0468E566C92275DD252995A1A9E942EBFD2F`
- 测试结束后两个节点均恢复正式固件。

## 结论

- 压力测试已覆盖真实双节点、90%+ 总线负载、每节点 1000 次请求。
- UDS 超时率与物理背景帧缺口分栏统计，不再混用。
- DTC、NRC、通信丢失和 Bus-Off 场景均有硬件证据。
- 高负载退化数据保留，后续第 9 周稳定性阶段继续修复和复测。
