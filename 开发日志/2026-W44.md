## 技术进展

- 新增 `diagnoser/tools/stability.py`：按时长运行双节点只读 UDS 请求，
  按分钟采样请求数、成功数、超时数、异常数和响应时间。
- 新增 `stability` CLI：支持运行时长、请求间隔、采样间隔、主机负载和报告路径。
- 支持 `--load 0` 与板内 `-StressMaster` 测试镜像配合，避免单只 slcan
  同时承担高负载发送和接收。
- 工具中断时保留部分采样和累计结果，但不会把中断运行标记为完成。
- 新增短时虚拟双节点测试，覆盖完整时长、周期采样、人工中断、UDS 超时
  独立计数和 CLI 报告路由。
- 新增板内 `-LoadGenerator`，在 F407 正常处理 UDS 的同时生成约 90% 背景负载。
- 新增 `-PeerStability`，F407/F103 每 100 ms 互为诊断端读取 `0xF19A`。
- CAN RX 改为硬件 FIFO0/FIFO1 分流和软件优先队列，负载帧不会排在诊断帧前。
- 负载源只使用完全空闲的 TX 邮箱，优先保证 UDS 响应和 Peer 请求。
- 新增 `-FrameLossBench`：双节点使用 `0x6F0/0x6F1` 各发送固定数量序号帧。
- 新增英文 README 和第 10 周终测流程。
- 250 µs 板内负载镜像完成 4.046 小时连续运行；F407 成功
  `145596/145673`，F103 `145650/145650`，两端无意外复位。
- 三轮独立 CH2 Bus-Off 注入完成：F407 `Bus-Off=3`、恢复成功 `3`，
  最终 error-active/TEC=0，无复位。
- 10,000 帧正常负载终测通过：F407→F103 物理丢失 `0.04%`，
  F103→F407 为 `0%`。
- 90% 负载 2000 帧补充测试完成：实际发送 `1000+1000`，物理丢失

## 验收边界

- 稳定性工具的 PASS 只表示软件完成请求时长且节点工作线程未异常退出。
- UDS 超时不等同于物理 CAN 帧丢帧。
- 4 小时和终测的原始 ST-Link 数据、设备标识与 COM 口仅保存在本地。
