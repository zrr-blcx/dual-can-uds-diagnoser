## 代码变更与测试

- 新增 `firmware/common/uds_server.h/.c`：不依赖 STM32 HAL 的 UDS 服务器核心。
- `0x10` 支持 Default、Extended、Programming 会话以及正响应抑制位。
- S3server 默认 5 秒，有效 `0x22/0x3E` 请求会刷新计时，到期回退 Default。
- `0x22` 支持单 DID 和多 DID 读取；无效 DID 返回 `7F 22 31`。
- `0x3E` 支持 `00/80` 子功能并刷新 S3。
- 新增 `diagnoser/uds/dids.py`，统一 VIN、硬件版本、自定义数据、CAN 健康和
  故障控制 DID。
- `VirtualEcu` 新增真实 S3 会话超时计数和 `0xF190` VIN 数据。
- 新增 `diagnoser/tools/uds_smoke.py` 与 CLI 命令 `uds-smoke`。
- 新增 `tests/firmware/uds_server_test.c` 和 Python 编译执行包装。
- 完整测试结果：`39 passed`，1 条 `.pytest_cache` 权限警告。
- F407 构建结果：`text=10596, data=12, bss=1636`。
- F103 构建结果：`text=9104, data=20, bss=1636`。
- 单节点虚拟联调覆盖 `10 03`、`22 F1 90`、`22 F1 93`、`22 01 00` 和无效 DID。
