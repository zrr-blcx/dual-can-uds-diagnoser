# 开发日志

每周一篇，记录项目二的开发进展、技术知识与复盘。

## 命名规则

- 文件名：`YYYY-Www.md`，例如 `2026-W36.md`
- 周期：ISO 周，周一至周日
- 生成时机：每周日晚上由例行任务整理并提交

## 每篇日志应包含

- 本周概览：项目目标、当前状态、测试结果
- 开发路径：按日期记录任务与进展
- 技术知识点：本周新接触或巩固的技术内容
- 代码变更与测试：改了什么、验证了什么
- 问题与复盘：卡点、解决过程、经验
- 下周计划：可勾选的下一步行动

## 维护约定

- 每周只写实际发生的进展，中断了就如实记录。
- 所有日志提交到 GitHub，形成连续的项目轨迹。
